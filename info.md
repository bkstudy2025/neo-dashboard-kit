# Neo Dashboard Kit

Glassmorphism cards for Home Assistant — one card that adapts to your device.
Glassmorphism-Karten für Home Assistant — eine Karte, die sich anpasst.

📚 **Docs:** [🇩🇪 Deutsch](https://github.com/bkstudy2025/neo-dashboard-kit/blob/main/docs/de/README.md) · [🇬🇧 English](https://github.com/bkstudy2025/neo-dashboard-kit/blob/main/docs/en/README.md)

## Prerequisites / Voraussetzungen
- **Card Mod** (HACS · Frontend) — required / erforderlich
- **Neo Dashboard Tools** (HACS · Integration) — recommended / empfohlen

## Quick start
1. Install via HACS (the resource is added automatically).
2. *Add card* → search **“Neo Card”** → pick a **card type** → choose an **entity**.

The picker has **three** cards that adapt to the chosen entity:
- **Neo Control** — anything controllable (light, switch, cover, climate, media, lock, alarm, scene/script)
- **Neo Display** — sensor values & cameras
- **Neo Header** — headings / dividers

Everything else is added via **modules** & **Premium** (editor → *Extensions*).
